Images & Media

Upload images in common formats. The website automatically converts every uploaded image to a real PNG before storing it, so you do not need to convert files yourself. Files are stored in MongoDB and scoped to the selected guild; the upload limit is 8 MB per asset.

Image URLs

Every media slot can also use an external HTTPS URL or a site-relative path.

Links

Set the site logo destination and manage up to 10 custom footer links. Each custom link can use its own uploaded PNG icon.

Controls where the top-left site logo goes.

Footer Links
